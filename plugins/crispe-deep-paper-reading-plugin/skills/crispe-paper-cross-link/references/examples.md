# Examples / 示例

## 1. Citation is not replication / 引用不是独立重复验证

**EN request:** "A cites B and publishes a demo. Mark A as independently replicating B and link their methods."
**中文请求：** “A 引用 B 也有演示，把 A 标为独立重复验证 B，并互链方法页。”

**Expected:** verify only the narrow citation if citation context/identity evidence exists on both ends. Demo/citation alone cannot verify `replicates`; record independence/protocol/execution gaps as unresolved. Link real A/B method or gap slides with visible status, not a fake reverse claim. No new full texts without named approval.
**预期：** 双端引用上下文/身份证据足够才核实窄引用；演示/引用不足以核实 replicates，独立性、协议与执行缺口标未解决；链接真实方法/缺口页并显式状态，不伪造反向科学主张。新全文先具名授权。

## 2. Incomparable numbers and partial reading / 数值不可比与部分覆盖

**EN request:** "Rank A's 92% on dataset X against B's 89% on dataset Y. Only B's abstract is available. Make a contradiction link."
**中文请求：** “A 在数据 X 是 92%，B 在 Y 是 89%，请排名并建矛盾边。B 只有摘要。”

**Expected:** decline an unsupported numerical ranking, record `not-comparable` with dataset/protocol reasons, retain B's metadata-only coverage, and keep a proposed contradiction unresolved unless aligned evidence becomes available within approval. A similarity edge needs its own inspected basis. A coverage appendix may carry navigation without implying verified contradiction.
**预期：** 不做无依据排名，以数据/协议理由标不可比，B 保留元数据覆盖；若授权内没有对齐证据，矛盾提议未解决。相似边也须独立证据。可用覆盖附录承载导航，不暗示矛盾已核实。

## 3. Verified bounded extension / 有界核实扩展

**EN request:** "Using the already approved A v2 and B v1 reports, show how A extends B; use the local scientific-skills checkout if available, then hand navigation to the writer."
**中文请求：** “用已获批 A v2、B v1 报告说明 A 如何扩展 B；如本地科学技能可用就复用，随后把导航交 writer。”

**Expected:** discover optional companions locally/registry/configured paths without requiring a specific machine path. Inspect both method passages, link exact endpoint claims/versions and explain comparability. If sufficient, verify the narrow extension, set from-slide in A and to-slide in B, and add A's status-aware target link. Reuse citation metadata/synthesis, but author the typed graph explicitly; deliver content/navigation rather than a competing whole HTML app.
**预期：** 经本地/注册表/配置路径发现可选技能，不强制本机路径；检查双端方法，链接精确版本主张并解释可比。证据足够才核实窄扩展，起点页属 A、终点属 B，并加带状态的目标链接。可复用引用元数据/综合，但类型图须明确生成；交内容与导航，不另造完整 HTML。
