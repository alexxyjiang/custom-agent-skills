# Shared project contract / 共享项目契约

The authoritative v1 schema, version/coverage/score rules, locale-qualified filenames, evidence relations and figure fields live in [the writer contract](../../crispe-slides-writer/references/contracts.md). Read it before creating or modifying a bundle; do not maintain a second schema here. A missing companion file must be reported before handoff, not replaced with guessed fields.
唯一权威v1模式及版本/覆盖/评分、语言文件、证据关系和图表字段见writer契约。创建修改前读取，不在此维护第二份；缺文件须交接前说明，不猜字段。

The orchestrator owns scope and approvals, analyst owns claims/scores, cross-link owns relation evidence/navigation, and writer/html-slides own presentation. Preserve every existing id and source unless a verified correction requires updating all references. General generation and PDF integration are documented by their owning skills, not duplicated in this contract pointer.
编排管范围授权、分析管主张评分、互链管关系导航、writer/外部技能管呈现；保留id和来源，核实修正时同步引用。生成及PDF集成由所属技能说明，不复制到契约指针。
